# 부록 D: 한계 돌파 챌린지 1 — 에이전틱 AI 워크플로우

지금까지 코딩을 할 때, "이 코드를 짜줘"라고 한 단계씩 구체적으로 지시하는 마이크로 매니지먼트(Micro-management) 방식을 주로 사용해왔다면, 이제는 도구를 다루는 관점을 바꿀 때입니다.

에필로그에 제시된 '기존 앱 고도화 챌린지'나 새로운 기능을 구현할 때, **"목표 지향적 지시(Goal-oriented)"** 방식으로 도구를 사용해 보세요. 이것이 로컬 AI IDE를 넘어서는 최신 트렌드인 **에이전틱 AI(Agentic AI)** 워크플로우입니다.

## 1. 챗봇(Chatbot) vs 에이전트(Agent)

- **챗봇 (과거)**: "D1 DB에서 예약 통계를 가져오는 SQL 쿼리를 짜줘." → 코드를 복사해서 내가 직접 파일에 붙여넣고 실행함. 에러가 나면 다시 복사해서 물어봄.
- **에이전트 (현재/미래)**: "관리자 대시보드 페이지를 만들고 싶어. DB 스키마를 확인해서 통계 API를 만들고, 프론트엔드에 `AdminDashboard.vue` 컴포넌트를 만들어서 라우터에 연결해. 작업이 끝나면 `npm run dev`로 서버 띄워서 에러 없는지 확인까지 해."

## 2. 에이전틱 AI 100% 활용 가이드

Antigravity IDE는 훌륭한 에이전트입니다. 권한을 주면 여러 파일을 동시에 열고, 스스로 코드를 수정하며, 터미널 명령어를 실행합니다.

{% hint style="info" %}
**에이전트에게 일을 맡기는 프롬프트 공식**

1. **명확한 목표(Goal) 제시**: 최종적으로 사용자가 화면에서 무엇을 할 수 있어야 하는가?
2. **제약 조건(Constraints) 명시**: 어떤 기술 스택을 써야 하는지, 어떤 파일은 건드리면 안 되는지.
3. **스스로 검증하도록 지시**: "작업 완료 후 테스트 코드를 돌리거나, 브라우저 콘솔 에러가 없는지 스스로 확인해."
   {% endhint %}

**실습 프롬프트 예시**:

> 💬 "지금부터 넌 내 전속 시니어 풀스택 개발자야. 현재 프로젝트에 '관리자 대시보드' 기능을 추가할 거야.
>
> 1. D1 데이터베이스 스키마를 읽어보고 필요한 API 엔드포인트를 설계해.
> 2. 프론트엔드 라우터에 `/admin`을 추가하고, 인증 가드를 적용해.
> 3. 차트 라이브러리(Chart.js)를 설치해서 예약 통계를 시각화해.
> 4. 모든 작업은 네가 직접 파일을 수정해서 반영하고, 진행 상황을 단계별로 나한테 보고해."

이 과정에서 AI가 스스로 계획을 세우고(Plan), 코드를 수정하고(Act), 터미널 출력을 보며 스스로 디버깅하는(Observe) 놀라운 광경을 목격하게 될 것입니다. 이것이 AI와 함께 일하는 미래의 개발 방식입니다.

## 3. 대중적인 에이전틱 AI 솔루션과 Antigravity 2.0

현재 개발 생태계에서는 '단일 파일 자동완성'을 넘어선 에이전틱 솔루션들이 폭발적으로 성장하고 있습니다.

- **Devin / AutoGPT**: 코딩부터 배포까지 스스로 계획하고 수행하는 자율형 AI 소프트웨어 엔지니어.
- **Cursor / GitHub Copilot Workspace**: 프로젝트 작업 공간 전체를 이해하고 다중 파일 편집과 에러 해결을 주도하는 차세대 IDE 환경.

**그리고, 다가올 Antigravity 2.0**
우리가 이 책에서 사용한 Antigravity IDE 역시 에이전틱 패러다임에 맞춰 **Antigravity 2.0**으로 진화하고 있습니다. 2.0 버전에서는 개발자가 목표만 던져주면 AI가 **스스로 하위 작업(Sub-tasks)을 분할하고, 백그라운드에서 코드를 작성하며, 브라우저를 열어 UI 기능 테스트까지 자동화**하는 완전한 형태의 자율 에이전트 경험을 제공할 예정입니다. 다가올 미래의 코딩 방식을 미리 준비해 보세요!
