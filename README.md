# 바이브 코딩 심화편

환영합니다! 이 책은 기초편에서 바닐라 HTML/CSS/JS로 완성했던 **사마르칸트 맞춤형 투어 가이드 매칭 앱**을 진짜 상용 서비스 수준으로 고도화하는 여정입니다.

기초편과 동일하게 **"AI에게 지시하고(프롬프팅) → 생성된 코드를 뜯어보며 원리를 깨우치는(귀납적 이해)"** 사이클로 진행됩니다. 문법책을 펴지 않고도, Vue.js·TypeScript·결제·인증·모바일 앱까지 만들어내는 진짜 바이브 코딩을 경험하세요.

## 이 책에서 만드는 것

1권의 정적 웹페이지를 → **로그인, 결제, 다국어, 모바일 앱스토어 출시**가 가능한 글로벌 서비스로 탈바꿈시킵니다.

## 기술 스택

- **로컬 개발 환경**: Antigravity IDE
- **프론트엔드**: Vue.js 3, TypeScript, Vite + vite-ssg
- **백엔드 및 배포**: Cloudflare Pages Functions, D1 (SQLite)
- **비즈니스 기능**: Stripe (결제), vue-i18n (다국어), JWT (인증)
- **모바일**: PWA + Capacitor + 푸시 알림 (앱스토어 출시)
